# Pt JadeBoard v1.0.0

首个公开发行版：Android 10+ / arm64-v8a，含中英双语离线语音模型。

- 中文全拼/简拼、候选记忆与保守纠错，英文输入及符号/Emoji/短语/剪贴板。
- 可导入主题；常用符号持久保存，修复候选刷新和符号页返回闪烁。
- 本机离线语音、录音状态及音量条；不依赖系统语音服务。
- 可选三小时长条草稿与用户自建 HTTPS 内网回传；同 App 连续输入合并，闲置五分钟/换输入 App 分段。
- **草稿和回传均默认关闭**。数字遮蔽不是匿名化，开启后会记录并发送非数字文本、来源 App 与时间。
- 内网地址校验、禁止重定向、保留 TLS 校验、每设备独立密钥、Android Keystore 加密凭证。

## 下载

安装 `Pt-JadeBoard-v1.0.0-arm64-v8a.apk`。`SHA256SUMS.txt` 提供文件校验；词库对应源数据在 `Pt-JadeBoard-v1.0.0-lexicon-source.zip`，保留原 GPL-3.0-only 条款。

仅分享 APK 不会带走你的数据库、地址或密钥，其他人全新安装不会自动连接你的电脑。请勿分享你的配对密钥或应用数据备份。

## 升级与限制

Release 使用独立签名，不能覆盖旧 Debug 版。卸载旧版会删除数据，目前没有全量迁移工具；请先自行保存所需内容，不要直接卸载。由测试版升级时，草稿与回传需重新开启。

首次语音按需加载，模型闲置 60 秒释放。发送间隔依赖输入法进程存活，不保证后台准点；手机删除不触发电脑删除。普通聊天框中的敏感文字无法自动识别。
