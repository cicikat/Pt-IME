# Pt JadeBoard v1.0.1

本次更新集中在三小时草稿召回、自建后端回传和外观自定义。Android 10+，仅支持 arm64-v8a。

- 草稿记录支持三小时内召回，同 App 连续输入合成长条，并显示逐条回传状态。
- 回传增加编辑事件、及时模式、连接测试和明确的保存流程；支持私网、回环、Tailscale 与用户主动允许的公网地址。
- 可导入 JSON 主题包、图片或动图背景、TTF/OTF 字体，并调整裁剪、压暗和按键透明度。
- 修复拼音整句过度拆音节、符号/Emoji 面板导航及中文输入法子类型声明。
- 草稿记录和自动回传仍默认关闭；密码、邮箱等敏感输入框不记录，语音音频不落盘、不上传。

## 下载

安装 `Pt-JadeBoard-v1.0.1-arm64-v8a.apk`。`SHA256SUMS.txt` 可校验附件；对应词库源数据位于 `Pt-JadeBoard-v1.0.1-lexicon-source.zip`。

正式版使用与 v1.0.0 相同的发布签名，可直接覆盖 v1.0.0。Debug 版签名不同，不能直接覆盖；卸载应用会清除本地草稿、短语、主题和其他数据。
