## 1. 已确认决策

### 1.1 产品名称

- 所有用户可见名称统一为“Pt键盘”。
- 包名 `com.chacha.jadeime`、类名和内部兼容标识暂不改，避免破坏 Android 输入法注册与升级。

### 1.2 主题文件格式

采用“ZIP 主题包 + JSON 配置”结构，而不是只导入单个 JSON。

```text
pt-theme.zip
├── theme.json
├── background.jpg/png
├── font.ttf/otf
├── key-press.json
└── idle-animation.json
```

- `theme.json` 描述颜色、尺寸、透明度、字体、动画开关和资源路径。
- ZIP 负责携带图片、字体和动画资源，保证导入/导出后路径不失效。
- 内置主题继续作为默认主题；导入主题不覆盖内置文件。

### 1.3 背景与字体

- 背景图片支持导入，存放在主题包私有目录。
- 字体支持导入 `.ttf` / `.otf`，由主题配置选择。
- 字体加载失败时回退系统字体，不得影响输入法启动。

### 1.4 透明度

提供两种互斥模式：

- 全局模式：统一调整整个键盘或主要区域透明度。
- 独立模式：分别调整背景、按键、候选栏、工具栏，并预留单键覆盖能力。

透明度值限制在 `0.0..1.0`，非法值使用默认值。

### 1.5 动态效果

- 支持按键按下动画和待机状态动画资源导入。
- 动画只允许声明式资源/参数，不允许运行主题代码。
- 粒子效果可以作为可选能力，但默认关闭、可单独关闭，并受严格性能上限约束。

## 2. 性能与稳定性红线

- 不得阻塞 `InputMethodService` 主线程、候选计算线程或 `commitText` 路径。
- 动画必须限制绘制区域、对象数量和刷新率；建议粒子上限 16~24 个。
- 动画不得在每帧创建大量对象或触发数据库/磁盘 I/O。
- 输入、删除、候选刷新优先级高于视觉效果；设备掉帧时自动降级或关闭动画。
- 主题资源损坏、字体不兼容或动画解析失败时，回退默认主题，不得导致 IME 崩溃。

## 3. 版本校验决策

主题包必须带版本信息：

```json
{
  "formatVersion": 1,
  "minAppVersion": 12,
  "name": "我的主题"
}
```

- `formatVersion` 不支持：拒绝导入。
- `minAppVersion` 高于当前版本：提示升级并拒绝启用。
- 缺失非关键字段：使用默认值。
- 图片过大、字体格式非法、动画资源超限：拒绝对应资源或整包导入。
- 导入前备份当前主题，失败自动回滚。

## 4. 施工阶段

### A. 主题模型与资源目录

- 扩展 `JadeTheme` / `SnabThemeJson`：透明度模式、区域透明度、字体和动画配置。
- 实现主题 ZIP 解包、私有目录管理和资源路径解析。
- 保持现有 JSON 单文件导入兼容，旧主题按默认资源处理。

### B. 设置页面

- 新增主题导入、导出、启用、关闭、删除按钮。
- 增加背景图和字体选择/预览。
- 增加全局/独立透明度切换及区域滑块。
- 导入失败显示原因，不改变当前可用主题。

### C. 输入法渲染接入

- 将透明度和字体应用到背景、按键、候选栏、工具栏及 Emoji/符号面板。
- 保持布局 JSON 与主题资源解耦；本工单不改变键盘布局格式。
- 在真实 IME 窗口验证主题切换即时生效。

### D. 动画播放器

- 先实现按键按下和待机动画的轻量版本。
- 动画播放器必须可关闭，并有资源大小、帧率、对象数量限制。
- 粒子效果作为后续可选阶段，先做性能基准和掉帧保护，再决定是否开放更多能力。

## 5. 验收标准

- 默认主题行为与当前版本一致。
- ZIP 主题可导入、启用、导出、删除和关闭。
- 背景图、字体、全局透明度、独立透明度在键盘和 Emoji/符号面板可见。
- 非法版本或损坏资源不会导致输入法崩溃。
- 连续快速输入中文时，候选延迟和输入稳定性不因主题动画明显下降。
- 每完成阶段 A/B/C/D，执行 `testDebugUnitTest` 和 `assembleDebug`；最终由真机验收。
