# JadeBoard 后续待办

本文档记录当前窗口尚未完成的功能，按依赖顺序排列。

## 1. 录音权限设置入口

- 在设置 Activity 增加录音权限状态显示。
- 提供跳转系统应用权限页的按钮。
- 权限拒绝时保持普通空格输入可用。
- 验收：首次长按空格不会崩溃；授权后无需重启输入法即可使用；永久拒绝时提示明确。

## 2. 语音语言跟随输入模式

- 将 `ImeRoot` 的当前 `InputMode` 传给语音回调。
- 中文模式使用 `zh-CN`，英文模式使用 `en-US`。
- 识别失败、超时、无服务时释放 recognizer 并恢复空格键行为。
- 验收：中英文模式各录一段，识别语言正确；松开空格后只提交一次结果。

## 3. 三小时库查看页面

- 在设置中增加“最近输入（3小时）”页面。
- 按时间倒序显示时间、应用包名、来源和已脱敏文本。
- 提供单条复制、全部清除；复制操作本身不重新写入三小时库。
- 默认不显示原始明文；数据库只保存脱敏内容。
- 验收：阿拉伯数字显示为 `*`，中文数字保留；过期数据不可见。

## 4. 内网增量回传

- 设置项：启用开关（默认关闭）、内网/组网地址、配对密钥、发送间隔。
- 仅发送新增三小时记录，使用记录 ID 去重。
- HTTPS/WSS，连接失败指数退避；不得写入原文日志。
- 回传前再次确认敏感字段和脱敏规则。
- 验收：关闭开关时无网络请求；断网恢复后不重复、不丢失；撤销密钥后停止发送。

## 5. 长按删除清空与恢复

- 在 `JadeImeService` 增加普通文本编辑框快照。
- 长按删除：保存光标前后文本并清空当前输入。
- 清空后的下一次删除点击：恢复快照和光标位置；再次点击恢复正常删除。
- 密码、邮箱、支付等敏感输入禁用该功能；跨应用、切换输入框、结束会话时清空快照。
- 验收：普通文本可清空/恢复；敏感字段不触发；切换应用不会串恢复内容。
